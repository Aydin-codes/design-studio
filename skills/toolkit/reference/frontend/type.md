## Font sources

**Default**

- [Google Fonts](https://fonts.google.com) (search: Google Fonts). Licence: mostly OFL (check each family). Get it: CDN link, or self-host through Fontsource. *(candidate)*

**Strong alternatives**

- [Fontsource](https://fontsource.org) (search: Fontsource npm fonts): use when you want to self-host Google and other open fonts as npm packages. Licence: per font, mostly OFL. Install: `npm i @fontsource/<font>`. *(candidate)*
- [Fontshare](https://www.fontshare.com) (search: Fontshare Indian Type Foundry free fonts): use when you want high-quality free fonts that aren't on Google Fonts. Licence: free, not open source (ITF licence); load from Fontshare's CDN, don't redistribute. Get it: CDN link from fontshare.com. **Use only from the source; never copy its files or code into another repo.** *(candidate)*
- [Velvetyne](https://velvetyne.fr) (search: Velvetyne libre fonts): use when you want experimental, characterful display faces. Licence: OFL. Get it: download. *(candidate)*
- [Collletttivo](https://www.collletttivo.it) (search: Collletttivo open source type foundry): use when you want contemporary open-source faces from independent designers. Licence: OFL. Get it: download. *(candidate)*
- [Uncut](https://uncut.wtf) (search: uncut.wtf libre typeface catalogue): use when you want a curated catalogue of contemporary libre fonts. Licence: OFL (check each). Get it: download from each font's page. *(candidate)*

**Big lists**

- [Velvetyne Libre Friends](https://velvetyne.fr/velvetyne-libre-friends) (search: Velvetyne Libre Friends free foundries list). Licence: list of OFL / libre foundries. *(candidate)*
- [Free Faces](https://www.freefaces.gallery) (search: Free Faces gallery free typefaces). Licence: mixed; check each font. *(candidate)*
- [awesome-typography](https://github.com/Jolg42/awesome-typography) (search: Jolg42 awesome-typography). Licence: list. *(candidate)*

**Paid** (only when asked, or when no free option fits)

- [Adobe Fonts](https://fonts.adobe.com) (search: Adobe Fonts). Licence: paid (with a Creative Cloud plan). Free option: Google Fonts or Fontshare. *(candidate)*

## More libre foundries

- [Open Foundry](https://open-foundry.com) (search: Open Foundry open source typefaces): use when you want to test fonts on a clean specimen page first. Licence: OFL. Get it: download. *(candidate)*
- [The League of Moveable Type](https://www.theleagueofmoveabletype.com) (search: League of Moveable Type): use when you want classic, well-made open-source faces. Licence: OFL. Get it: download. *(candidate)*
