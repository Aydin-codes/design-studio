# References

**Frankenstein, not "which is closest"** (method from Kole Jain). For each section (hero, proof, features, pricing, call to action) or each screen, pick one real reference and note what to change: "this hero, but with the product's objects scattered"; "these tabs, with a bigger image and 90% less text." Keep only the wireframe; discard their styling.

Pick references whose technique fits this product (rule 1). A technique only transfers if it shows what this product does.

**Human-made and shipped.** A reference is a real product, site, app or printed piece that people designed and shipped. Not AI-generated galleries, not concept shots made for likes (most of Dribbble and Behance), not your own earlier output. If you can't tell who made it or whether it shipped, don't use it.

**Ask first.** The user's own references beat anything you find. Ask once; if they have none, find two or three, from different angles (a same-category leader, a quiet brand, one from a different field with the right feel).

**Show real screenshots, not names.** Most users can't describe what they like but recognize it instantly. Capture screenshots (or ask the user for links) and show them; ask which parts they'd take.

## Reference types
- **Top product sites:** Scale AI, Railway, Render, Raycast, Igloo, Brilliant, Linear, Stripe, Vercel, Cursor, Resend.
- **Tech-forward hardware and defense:** Anduril, Helsing, Shield AI, Saronic, Nothing, Rivian, Framework. Real 3D renders, technical type, confident restraint.
- **Quiet brands,** simple but unmistakably themselves: Apple, Aesop, Patagonia, Notion, Teenage Engineering.
- **Same-category sites:** competitors and neighbors, to see the category's defaults (and avoid them).
- **The user's own picks** from the taste profile.

## Sources
Mobbin if connected (the MCP needs a paid plan); Figma frames if the user has them (start from those); otherwise free galleries (godly.website, land-book.com, Awwwards) or sites the user names. Present 6-8, ask which parts they'd take and why, and record the answers in the taste profile.

## Identity board (Deep)
Start from one image that carries the mood. Pull the palette from images, add one or two accents, pick textures and type from the subject's world, then icons in the accent colors. Every choice goes through a picking sheet (`picking-sheets.md`).
