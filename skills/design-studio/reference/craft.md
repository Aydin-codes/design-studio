# Craft (always)

Correct-or-incorrect rules. They apply to every output, alongside the output file's own rules.

- Responsive down to 375px wide.
- Visible keyboard focus; AA contrast; reduced-motion respected.
- Tokens instead of one-off values; one spacing scale.
- Real content, never lorem ipsum.
- Every interactive component has every state: default, hover, pressed, focus, disabled, loading, empty, error.
- Tap targets at least 44px on touch screens.

## Copy
- Write from the reader's side; name things by what people recognize.
- A button says what happens ("Start a scan", not "Get started"). The same action keeps its name everywhere.
- Specific beats clever. No filler.
- **Never explain design choices on the page.** Notes about palettes, fonts, sources or "this is a mock-up" go in `DESIGN.md` or one small credit line where a licence requires it, never in the product's copy.
- **The any-product test:** for every headline, feature line and button, ask "could this sentence describe any other product?" If yes, rewrite it with a specific name, number or example from this product, or delete it.
- No invented testimonials, numbers, clients or sources. If proof is missing, leave a marked placeholder.
- Errors say what went wrong and how to fix it. Empty states point to the first action.
